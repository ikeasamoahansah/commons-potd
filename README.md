# commons-potd

Set your Linux desktop wallpaper to the **[Wikimedia Commons Picture of the
Day](https://commons.wikimedia.org/wiki/Commons:Picture_of_the_day)** — with a
preview window so you can confirm the picture before it goes on your desktop
(on the rare days when a POTD consists of more than one file, you can pick
between them).

## Features

- Fetches the day's picture straight from the Wikimedia APIs — no scraping.
  Two sources, in order: the Commons `Potd/` template page, plus the
  featured-feed API so "today" works even before its template page exists.
  Thumbnail URLs are snapped to Wikimedia's allowed sizes
  (`20…960 / 1280 / 1920 / 3840 px`) — arbitrary widths now get rejected
  (HTTP 400) by Wikimedia.
- Preview window (Tkinter, no extra GUI toolkit): click a card to select,
  double-click or press **Return** to apply, **Esc** to quit, right-click a
  card to open its Commons file page. Pillow renders JPEG/WebP previews
  through an in-memory PNG conversion.
- Sets the wallpaper on GNOME (incl. Ubuntu light/dark variants), KDE Plasma,
  XFCE, and `feh`/`swaybg` window managers.
- Wallpaper-size download (matched to your monitor; up to 4096 px), cached in
  `~/.local/share/backgrounds/` so the file survives cache clears.
- Optionally run unattended (`--auto`) via systemd timers or autostart.

## Installation

```bash
# from a checkout
python3 -m pip install .
# or just run it in place:
python3 -m potd
```

`requests` and `pillow` are the dependencies; Tkinter is expected to ship
with Python (on Ubuntu: `sudo apt install python3-tk python3-pil`).

## Usage

```bash
potd                          # preview today's picture, confirm, apply
potd --auto                   # no preview; take the first image right away
potd --index 2                # take the second image, no preview
potd --date 2026-11-07        # a specific day
potd --width 3840             # force 4K downloads (for fractional scaling)
potd --list                   # show the day's images and exit
```

Click behaviour in the preview: **click** to select, **double-click** or
**Return** to set as wallpaper, **right-click** to open the Commons page,
**Esc** to cancel without changing anything.

## Run it every day at 00:00

The clean way on modern Linux desktops is a **systemd user timer** (no root
needed; `--auto` means no window is opened).

Create `~/.config/systemd/user/potd.service`:

```ini
[Unit]
Description=Set wallpaper to the Wikimedia Commons Picture of the Day

[Service]
Type=oneshot
WorkingDirectory=%h/programming/commons-potd
ExecStart=/usr/bin/python3 -m potd --auto
```

> If you installed with `pip install .`, you can drop the WorkingDirectory
> line and use `ExecStart=/usr/bin/potd --auto` instead.

Create `~/.config/systemd/user/potd.timer`:

```ini
[Unit]
Description=Daily Commons POTD wallpaper update at 00:00

[Timer]
OnCalendar=*-*-* 00:00:00
Persistent=true

[Install]
WantedBy=timers.target
```

Enable it:

```bash
systemctl --user daemon-reload
systemctl --user enable --now potd.timer     # starts now, fires at 00:00 daily
systemctl --user list-timers potd.timer      # confirm the next run
```

Notes:

- `Persistent=true` means a missed midnight (PC off or asleep) is caught up
  on the next time your session runs.
- User timers live inside your desktop session — they run while you are
  logged in (the normal case for a desktop). To have it fire right after
  login on days you were off at midnight, keep `Persistent=true`.
- Setting the wallpaper needs your graphical session's D-Bus, which exists;
  no X/Wayland access is required because `--auto` never opens windows.

Alternative, classic **cron** (fires at 00:00 too; `crontab -e`):

```cron
0 0 * * * cd ~/programming/commons-potd && /usr/bin/python3 -m potd --auto >/dev/null 2>&1
```

with the usual cron caveat: there is no catch-up if the machine was off.

## How it works

`Template:POTD/YYYY-MM-DD` on Commons lists the file(s) in use each day; the
tool reads them via the MediaWiki API, filters out icons/boilerplate, and
keeps the real candidates. Thumbnails are generated by Commons at the size
your screen needs (previews are transcoded to PNG so Tkinter can display
them).
